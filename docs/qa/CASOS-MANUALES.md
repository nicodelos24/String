## Registrar una ejecución

Usa el Excel [Casos de prueba String](excel/Casos_de_prueba_String.xlsx) como plantilla. Completa navegador, versión, dispositivo, pasos realmente ejecutados, resultado observado y evidencia. Guarda una copia con fecha. Si falla, vincula el ID del bug. No marques Aprobado sin ejecutar.
